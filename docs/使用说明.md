# SF HTML 导入工具使用说明

## 1. 推荐用法：直接双击 EXE

双击运行：

```text
SF_HTML转换工具.exe
```

这是已经打包好的 Windows 64 位窗口程序，适用于 Windows 10 / Windows 11，不需要安装 Python。

窗口里按这个顺序操作：

1. 粘贴 SF 上传 `token`，输入框默认隐藏。
2. 点击“添加HTML文件”添加一个或多个 `.htm/.html` 文件。
3. 如果要批量处理整个目录，点击“选择HTML文件夹”，程序会自动识别里面的 `.htm/.html` 文件。
4. 也可以直接把 HTML 文件或文件夹拖到文件列表。
5. 图片文件夹可以留空，程序会优先按每个 HTM 自动识别同名 `.files` 文件夹。
6. 先点“预演检查（不上传）”，确认图片都能匹配。
7. 再点“开始正式转换”，上传图片并生成可复制的 TXT。

输出规则：

- 转换结果放在 HTM 同目录下的 `已转换` 文件夹：`已转换\已转换_原文件名.txt`
- 上传映射和失败详情放在：`已转换\转换日志\已转换_原文件名_日志.txt`
- 如果同名 TXT 已存在，会自动生成 `_2`、`_3` 后缀，不覆盖旧文件
- 选择 HTML 文件夹或拖拽文件夹时，会自动跳过 `已转换` 结果目录，避免重复处理输出文件
- 完成后自动打开输出文件夹

生成的 `.txt` 里就是要复制到 SF 富文本源码模式的 HTML 内容。

## 2. BAT 备用启动

如果 exe 被安全软件拦截，或者你想用源码方式运行，可以双击：

```text
一键运行.bat
```

新版 `.bat` 会自动检查 Python 和依赖；如果出错，会停住显示原因，不会一闪而过。

## 3. token 填写方式

窗口里推荐只粘贴 token 本身。

如果你不小心粘贴了完整 Request URL，也可以兼容，例如：

```text
https://serviceforce.lenovo.com.cn/api/wb/upload/file?token=xxxx
```

## 4. 中文乱码处理

窗口里的“编码”默认是 `auto`。

如果输出中文异常，可以改成：

```text
gb18030
```

或者：

```text
gbk
```

再重新预演或转换。

## 5. 注意事项

- “预演检查（不上传）”生成的 TXT 里图片地址是 `DRY_RUN_URL/...`，只能用来检查，不要复制到 SF。
- “开始正式转换”生成的 TXT 里才是 SF 返回的真实图片地址。
- 如果正式转换失败并提示 token 过期，请重新登录 SF，重新复制上传 token。
